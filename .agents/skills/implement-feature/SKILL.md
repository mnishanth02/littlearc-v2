# Implement Feature

1. Run the `find-project-context` workflow.
2. Confirm the goal, scope, constraints, acceptance criteria, and delivery-state
   impact from `docs/IMPLEMENTATION_STATUS.md`.
3. Create or update the relevant implementation plan when the change is a
   work-package-sized or cross-module change.
4. Identify the minimum file set needed and follow existing package boundaries.
5. Implement the behavior with focused tests where practical.
6. Update affected docs, status, evidence, or ADRs when externally observable
   behavior, architecture, or delivery state changes.
7. Run focused validation first, then broader validation when practical.
8. Report files changed, behavior implemented, validation run, and residual
   risks.
