# Understand Feature

1. Run the `find-project-context` workflow.
2. Inspect relevant source, tests, package manifests, and configuration.
3. Trace behavior from entry point to shared package, persistence, or external
   integration boundary where applicable.
4. Identify applicable roadmap items, implementation plans, ADRs, and gates.
5. Report current behavior, important files, dependencies, tests, validation
   commands, and documentation conflicts or gaps.
6. Do not modify files.
