# M3 Vault Wedge

> **Status:** In progress
> **Last updated:** 2026-07-25
> **Owner:** Engineering
> **Milestone:** M3

M3 adds the parent-owned record vault, capture pipeline, search, and retrieval
behavior described in the implementation roadmap.

Gate 2 remains open. Founder direction on 24 July 2026 authorized the bounded
`VLT-01` record foundation, `VLT-02` manual record creation, and now separately
authorizes `VLT-03` capture and import adapters after plan review and
validation. These exceptions do not close Gate 2, authorize `VLT-04` or later
M3 breadth, or broaden any real-data, provider, physical-iOS, two-device,
low-end-Android, or pilot claim.
